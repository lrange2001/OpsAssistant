# 维护与排障

- **应用数据**:数据目录默认 `~/ForFreedom`(可在 设置 > 数据 改位置并整体迁移;位置记录在 `~/Library/Application Support/ForFreedomAssistant/datadir.txt` 指针文件,环境变量 `FF_DATA_DIR` 优先级更高)。目录内含检查点 checkpoints/、技能 skills/、子代理 agents/、自定义命令 commands/、记忆 memory/、用量 usage.json、自动化 automations.json、权限规则、MCP 配置、SSH 主机档案。删掉数据目录与指针文件 = 恢复出厂。
- **会话数据**:浏览器 localStorage(30 个会话 + 草稿 + 参数 + 历史),与文件系统数据无关。
- **改源码**:改 `backend/` 包内模块或前端后,仓库根跑 `zsh mac-app/update.sh` 重建重装(含语法检查);`zsh mac-app/test.sh` 冒烟。源码已 git 化,改动前可用 git 提交做一个回滚点,改坏了好退回。
- **连不上模型**:看顶栏连接点;确认 cc-switch 当前供应商可用;徽章显示 no API key 时去 cc-switch 配 key。
- **终端卡死**:Reset 重启 shell。
- **"Stream interrupted: null"(已修复)**:旧版在生成中切换会话会触发这条误报并打断流;现在每个会话独立成流,切走不打断、后台继续跑、切回内容完整。仍见到 "Stream interrupted" 时才是真的网络断流:部分内容保留,点最后一条消息的 Retry 重发。
- **停止的应用后台任务**:定时任务只在应用运行期间触发,重启应用后继续按计划执行。
