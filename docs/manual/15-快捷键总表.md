# 快捷键总表

| 按键 | 作用 |
| --- | --- |
| Cmd+K / Cmd+Shift+P | 命令中心(双默认) |
| Cmd+F | 页内查找(Enter/Shift+Enter 上一个下一个,Esc 关) |
| Cmd+J | 侧栏开关 |
| Cmd+B | 历史会话列表 |
| Cmd+Shift+L | 主题切换 |
| Cmd+N | 新会话 |
| Cmd+O | 设置工作目录(聚焦 dir 输入框) |
| Cmd+, | 设置 |
| Cmd+Shift+[ / ] | 上/下一个会话 |
| Cmd+[ / ] | 本会话内跳上/下一个用户问题 |
| Ctrl+M | 查看当前模型 |
| Ctrl+Shift+M | 循环权限模式 |
| Ctrl+T | 深度思考开关 |
| Cmd/Ctrl+Shift+T | 抓取终端新增内容为 TERM 引用 chip(SSH 终端优先,回落本地终端;终端聚焦时同样生效) |
| Cmd+1 | 聚焦消息输入框(终端聚焦时同样生效) |
| Cmd+2 | 聚焦当前 SSH 终端 |
| Cmd+3 | 轮换 SSH 终端(多标签间循环切换) |
| Cmd+4 | 收起/展开 SSH 面板 |
| Cmd+Shift+U | Coding/Office 切换 |
| Enter / Shift+Enter | 发送 / 换行 |
| Cmd/Ctrl+Enter(生成中) | 反向发送:排队模式=立即转向;引导模式=排队 |
| Esc | 停止生成;逐层关闭:命令中心 > 查找 > 设置 > 历史 > 状态面板 |
| ↑ / ↓(空输入) | 输入历史 |
| / @ $ | 命令 / 文件 / 技能建议 |

![浅色主题](../screenshots/chat-light.png)

*图:Cmd+Shift+L 切换的浅色主题*

以上全局快捷键都可在 设置 > 快捷键 里改绑:点击键位开始录制(Esc 取消,Backspace 恢复默认);与其他命令冲突会提示占用者,可"仍要绑定"接管;系统保留键(Cmd+C/V 等浏览器原生行为)与菜单固定键拒绝绑定;支持按命令名或组合键搜索;"全部恢复默认"一键还原。输入框内的 Enter/Esc/↑↓ 属固定键,不可改。

Mac 菜单栏另有 File / Edit / View / Window 菜单(新建、历史、设置、主题、缩放 Cmd+=/-/0、全屏)。
