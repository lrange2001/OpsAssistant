# 定时任务

设置 > 定时任务。无人值守自动执行提示词(后台跑完整 agent 循环,需确认的操作自动跳过),按本地时区调度,应用开着才触发:

- 频率:每 N 分钟 / 小时 / 天 / 周(选周几)/ 月(几号),加具体时刻(时:分)。
- 可循环或一次性(跑完自动停用)。
- 每个任务可:启停、**立即运行**、**运行记录**(查看每次的输出和轮次)、删除。
- **运行结果可转 ops 处理**:运行记录里每次运行旁有「转 ops 处理」按钮——点它自动新建一个 ops 会话、进入 ops 模式,并把该次运行结果预填进输入框(你过目后发送);模型会先采集涉及主机的画像再定位问题。前提是有在线 SSH 终端,没有时会提示先 `/ssh` 连接。
- 例:每天 9:00 "检查 ~/project 的 git 状态,有未提交改动就总结发出来"。

**当前边界**:无人值守循环只挂内置工具(run_shell / read_file / write_file / edit_file / list_dir / grep / glob / todo_write / task / web_fetch / skill),全部在本机执行,没有 SSH 操作能力——**远程服务器操作暂不支持**。run_shell 是本机 shell,理论上可以敲无交互的 ssh 命令行,但没有终端上下文、不接管主机档案与密钥,不视为支持远程操作。远程定位与处理走「运行记录 → 转 ops 处理」衔接:巡检发现异常后,一键带着结果进 ops 会话,由你在场逐条回车推进(见 09 章「ops 模式」)。
