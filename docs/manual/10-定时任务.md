# 定时任务

设置 > 定时任务。无人值守自动执行提示词(后台跑完整 agent 循环,需确认的操作自动跳过),按本地时区调度,应用开着才触发:

- 频率:每 N 分钟 / 小时 / 天 / 周(选周几)/ 月(几号),加具体时刻(时:分)。
- 可循环或一次性(跑完自动停用)。
- 每个任务可:启停、**立即运行**、**运行记录**(查看每次的输出和轮次)、删除。
- 例:每天 9:00 "检查 ~/project 的 git 状态,有未提交改动就总结发出来"。

**当前边界**:无人值守循环只挂内置工具(run_shell / read_file / write_file / edit_file / list_dir / grep / glob / todo_write / task / web_fetch / skill),全部在本机执行,没有 SSH 操作能力——**远程服务器操作暂不支持**。run_shell 是本机 shell,理论上可以敲无交互的 ssh 命令行,但没有终端上下文、不接管主机档案与密钥,不视为支持远程操作。后续规划:ops 模式(专门让 AI 操作 SSH 的模式)落地后,定时任务将能接入远程操作。
