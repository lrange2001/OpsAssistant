# 快速开始

应用位置:`~/Applications/ForFreedomAssistant.app`(双击启动)。

![欢迎页](../screenshots/welcome-dark.png)

*图:双击启动后首先看到的欢迎页*

1. **模型**:无需在此配置。用 cc-switch 切换供应商,顶栏徽章 2 秒内自动跟随(切换时会闪一下提示)。
2. **工作目录**:输入框上方 `dir` 行设置本次会话的工作目录。支持模糊补全(输入即提示,Tab/Enter 选中,继续输入 `/` 可进下一级),失焦时服务端校验,目录不存在会红字提示。所有命令、文件读写、git 操作都在该目录下执行。
3. 直接输入问题回车即可;输入 `/` 看全部命令,`@` 引用文件,`$` 调用技能。

界面默认纯黑主题、英文;设置面板为中文。模型输出全程无 emoji(服务端三层过滤)。
